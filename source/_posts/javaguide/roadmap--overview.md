这个模块把分散的学习内容按职业方向整理成几条完整路线，帮你根据目标选择路径，而不是在上百篇文章里来回跳。这篇导览说明每条路线适合谁、讲什么、怎么用。

<!-- more -->

## 为什么需要「路线」而不是「文章清单」

单篇文章解决一个知识点，路线解决的是知识点之间的依赖关系：先学什么、后学什么、学到什么程度算过关、什么时候该动手做项目。没有这张依赖图，最常见的结局是收藏了一堆教程，每个都开了头，能力却始终串不起来。

这个模块的路线有一个共同的设计原则：每个阶段都带可检验的验收标准，而不是「读完某篇文章」。学到没学到，用作品和指标说话。

## 各方向路线导览

### Java 后端方向

[Java 后端学习路线](/knowledge/interview-preparation/java-roadmap/)：从 Java 基础、集合、并发、JVM，到 Spring、数据库、分布式与项目实践，覆盖系统学习和求职准备的完整链路。适合在校生和准备后端面试的开发者，是其他几条路线的公共底座。

### AI 方向

[Java/Go 开发者 AI 应用开发与 Agent 学习路线](/knowledge/roadmap/java-to-ai-roadmap/)：面向已有后端经验、想把大模型能力接进业务系统的人。按 LLM 基础、Prompt 工程、RAG、Agent、工程化五个阶段展开，每个阶段给出目标与验收标准，并盘点了后端经验中可以直接迁移的资产。

[后端开发者转型 AI Agent 学习建议](/knowledge/roadmap/backend-to-ai-agent-roadmap/)：更偏决策与落地的一篇。先帮你判断要不要转，再讲清从 CRUD 到 Agent 的思维转变（确定性逻辑到概率系统），拆解 LLM API、工具设计、编排、评估四块技能栈，并给出三个由浅入深的实战项目选题。

两篇配合读：前者管知识体系，后者管转型节奏。

### 全栈方向

[后端开发者全栈学习路线](/knowledge/roadmap/full-stack-roadmap/)：目标是独立交付完整功能，而不是「会写点页面」。讲清前端的最小必要知识（JS/TS、一个框架、工程化常识），给出从改页面、联调、读脚手架到部署上线的四步补齐顺序，并结合 AI 编程工具说明高效的练习方式。

### 测试开发方向

[测试开发学习路线](/knowledge/roadmap/test-development-roadmap/)：面向测开、自动化测试与质量工程方向。讲清测开与业务测试的区别，拆解自动化框架、CI/CD、质量平台三块技能栈，补上了 AI 辅助测试与 AI 应用评测这两个新增项，并对岗位前景做了客观分析。

## 怎么使用这些路线

三条建议：

**先选一条主线，别多线并行。** 每条路线都是按「已有基础 → 目标岗位」设计的，同时追两条线往往两边都停在浅层。不确定选哪条时，默认先补后端底座，它是其余方向的公共依赖。

**按验收标准推进，不按阅读进度推进。** 每个阶段的标准达不到，就停下来补，而不是继续往后翻。卡住的位置通常就是真正的能力缺口。

**让项目成为终点，而不是收藏夹。** 每条路线的末端都是可写进简历、能讲清取舍的项目。路线可以收藏，但能力只能从动手里长出来。
