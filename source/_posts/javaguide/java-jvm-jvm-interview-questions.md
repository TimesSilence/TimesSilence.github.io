## 内存区域答法

线程私有：PC、栈、本地方法栈；共享：堆、方法区（JDK8 元空间）。直接内存不属于运行时数据区但常一起考。

<!-- more -->

## 对象创建五步

类加载检查 → 分配内存（指针碰撞/空闲列表）→ 零值初始化 → 设置头信息 → init 方法。逃逸分析可能栈上分配或标量替换。

## GC 追问

Safe Point 与 STW；G1 Remembered Set 跨区引用；ZGC 着色指针与读屏障。答收集器要绑定**停顿目标与堆大小**。

## 排查题

「频繁 Full GC」从元空间、老年代晋升、System.gc、大对象直接进老年代四条线展开。
