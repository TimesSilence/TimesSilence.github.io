## 高频起点题

**进程与线程**：进程是资源分配单位，线程是调度单位。Java 线程由 JVM 映射到 OS 线程（平台线程），虚拟线程则是轻量用户态调度。

<!-- more -->

**创建方式**：继承 Thread、实现 Runnable、Callable+FutureTask，或线程池。推荐后两种，便于复用与治理。

**sleep vs wait**：sleep 不释放锁，属于 Thread；wait 释放 monitor，必须在同步块内调用，属于 Object。

## 原创追问

「为什么 double-checked locking 需要 volatile？」——半初始化对象对其他线程可见会导致 NPE，这题把 JMM 与单例模式绑在一起，是区分背诵与理解的分水岭。
