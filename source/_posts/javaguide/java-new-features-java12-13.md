## Switch 表达式（预览）

箭头分支 yield 值，编译器检查穷尽性（配合 enum/pattern 后续完善）。减少 break 漏写 bug。

<!-- more -->

## 文本块（预览）

三重引号多行字符串，自动缩进处理。JSON/SQL 模板更清晰，注意转义规则在 15 定稿。

## GC

Shenandoah 实验（12）；ZGC 归还未用堆内存（13）。非 LTS 版本适合尝鲜预览语言特性，生产谨慎。

## 课堂外的思考

## 可复现实验

为每个主题保留最小复现：一段可运行的 Java 片段、一条 jcmd/jstack 命令，或一组压测对比。记录环境（JDK 小版本、CPU 核数、容器限制），结论才可靠。实验细节不必全部公开，但索引要能找到。
