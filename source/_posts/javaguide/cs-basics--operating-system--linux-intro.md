初识 Linux 不必先背命令，先建立三张地图：发行版怎么选、根目录下每个目录管什么、遇到问题该用哪组命令。本文按这三条线索整理 Linux 入门知识。

## 内核与发行版

严格说 Linux 只是内核——负责进程、内存、文件系统和设备管理的那部分。厂商和社区把内核连同包管理器、工具链、文档打包成开箱即用的系统，就是发行版。主流谱系可分两支：

| 谱系 | 代表 | 定位 |
| --- | --- | --- |
| Debian 系 | Debian、Ubuntu | 社区驱动，apt 包管理；Ubuntu LTS 在桌面与云上都很常见 |
| RHEL 系 | RHEL、Rocky、AlmaLinux | 商业企业级，dnf/yum 包管理，强调稳定与支持周期 |

CentOS 的老定位（RHEL 的免费重编译版）已随 CentOS Linux 停更成为历史，现行的 CentOS Stream 是 RHEL 的上游滚动分支，性质不同。学习企业环境选 Rocky/AlmaLinux，快速上手选 Ubuntu LTS，追求轻量稳定选 Debian。选型时关注两点：支持周期是否覆盖你的使用时长，以及目标生产环境用哪一支——学练环境尽量与线上一致，少踩"本地能跑、线上报错"的坑。

## 目录结构的设计哲学

Linux 目录树遵循 FHS（文件系统层次标准），核心思想是按"用途和变化频率"分家，而不是按软件分家：

- `/etc`：只放静态配置，不放可执行程序——查配置先来这里。
- `/var`：运行中会变的数据，日志、缓存、队列都在这，磁盘爆满先查 `/var/log`。
- `/proc`：procfs 伪文件系统，内容是内核实时生成的进程与系统状态，不占磁盘。
- `/sys`：sysfs 伪文件系统，暴露设备与内核对象，供设备管理等机制使用。
- `/usr`：系统软件的主体，程序与共享库集中于此。
- `/home`：用户主目录；`/tmp`：临时文件，重启可能清空；`/boot`：内核与引导文件；`/dev`：设备文件。
- `/opt` 留给第三方可选软件，`/mnt` 用于临时挂载。现代发行版普遍把 `/bin`、`/sbin`、`/lib` 合并为指向 `/usr` 下同名目录的符号链接，不必再纠结两边有什么区别。

把 `/proc` 和 `/sys` 记成"观察内核的窗口"而非真正的磁盘目录，很多怪现象（文件大小显示 0 却能读出内容）就不奇怪了。这也体现了"一切皆文件"的思路：进程、设备、内核状态都尽量用统一的文件接口暴露出来。

## 常用命令地图（按任务分组）

### 文件与目录

`ls`、`cd`、`pwd` 打底；`find /path -name "*.log"` 按名查找；`cp -r`、`mv`、`rm -rf`（慎用）做增删改；`cat`/`less`/`tail -f` 看内容；`chmod`、`chown` 管权限；`tar -zcvf`/`tar -zxvf` 打包解压；`scp`、`rsync` 跨机传输。

### 进程管理

`ps aux | grep xxx` 或 `pgrep -a` 找进程；`top`/`htop` 看实时占用；`kill` 发信号，先 `TERM` 后 `KILL`；`systemctl start|stop|status|enable` 管服务，`journalctl -u 服务名` 查服务日志。

### 网络

`ss -tlnp` 看监听端口（比 netstat 更快）；`ping` 测连通；`ip addr` 看地址；`curl` 测接口；`dig` 查 DNS。

### 磁盘与内存

`df -h` 看空间、`df -i` 看 inode；`du -sh *` 定位大目录；`free -h` 看内存（buff/cache 大是正常缓存，不必紧张）；`iostat -x 1` 看磁盘繁忙程度。

## 实践要点

- 排障遵循"指标链"：先看进程与负载，再看内存与缓存，再看磁盘空间与 inode，最后看网络与日志，避免一上来就重启服务。
- 权限最小化：不要用 `chmod 777` 偷懒；目录的执行位表示"能否进入该目录"，与文件的执行位含义不同，不能照搬。
- 软件安装优先用发行版包管理器，服务交给 systemd 管理；`kill -9` 是不给进程清理机会的强制手段，不作常规停止方式。

## 小结

- Linux 内核加上软件生态才是发行版；学习首选 Ubuntu LTS 或 Rocky/AlmaLinux。
- 目录按用途划分：`/etc` 管配置、`/var` 管变动数据、`/proc` 与 `/sys` 是内核窗口。
- 命令按任务记：文件、进程、网络、磁盘各一组；排障按指标链逐项排除，而不是背清单。
