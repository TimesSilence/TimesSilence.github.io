## 为什么需要 JMM

编译器与 CPU 会重排序，每个线程又有本地工作内存缓存。JMM 规定哪些写对其它线程可见，从而在不牺牲性能的前提下给出可推理的并发语义。

<!-- more -->

## happens-before 实例

对同一把锁 unlock happens-before 后续 lock；volatile 写 happens-before 后续读；线程 start 前动作 happens-before 线程内任意动作。

## 与 JVM 内存区域区分

JMM 是**语义模型**，讨论可见性/有序性；堆、栈是**运行时布局**。面试别混：「栈存局部变量」不等于「工作内存就是栈」。

## 小实验

两线程各写普通变量与 volatile 变量交叉读，用 JMH 或简单循环观察无同步时的非预期结果，加深「看不到最新值」的直觉。
