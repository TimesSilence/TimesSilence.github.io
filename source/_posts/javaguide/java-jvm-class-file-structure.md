## 文件骨架

魔数 CAFEBABE → 版本号 → 常量池（Utf8、Class、NameAndType 等）→ 访问标志 → 类/父类/接口索引 → 字段表 → 方法表 → 属性表（Code、LineNumberTable）。

<!-- more -->

## 为什么学结构

读懂字节码才能理解反射、动态代理、Lambda 生成类；排查 NoClassDefFoundError 时也常要确认常量池引用是否有效。

## 动手

```bash
javap -v Hello.class | head -40
```

对照输出找 constant_pool 里的 #1=#2+#3 形式，建立「符号引用 vs 直接引用」的直觉。
