## 五阶段

加载：读字节流生成 Class 对象。验证：文件/format/字节码/符号引用合法性。准备：静态变量零值分配。解析：符号引用转直接引用（可延迟）。初始化：执行 clinit。

<!-- more -->

## 初始化时机

new、反射、子类触发父类、主类、MethodHandle 等。接口 default 方法有特例。主动引用才初始化，被动使用父类静态字段不会初始化子类。

## 例子

```java
class Parent { static { System.out.println("P"); } }
class Child extends Parent { static { System.out.println("C"); } }
// 仅 Child.staticField 访问顺序：P → C
```

理解顺序有助于解释静态块死锁等诡异问题。
