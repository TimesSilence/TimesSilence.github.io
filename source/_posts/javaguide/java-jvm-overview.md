## 模块串联

先建立运行时数据区全景，再看 class 文件与类加载双亲委派；然后深入 GC 算法与收集器，配合常用 JVM 参数做压测；最后用 jcmd、MAT、Arthas 走一遍线上排查流程。

<!-- more -->

## 工具箱

jps/jstat/jmap/jstack 是 JDK 自带；VisualVM、GCeasy 看 GC 日志；heap dump 用 MAT 找泄漏 dominator tree。

## 实践建议

本地用 -Xlog:gc* 打开统一日志（JDK9+），调一次 Young GC 频率与 Full GC 触发条件，比背收集器名字更有体感。

## 课堂外的思考

## 与同事的讨论方式

我会用白板画出状态机、内存布局或调用链，请同事挑错。若被追问「更高并发或更老 JDK 版本会怎样」，答不上来就回到文首原文链接查 primary source，而不是凭记忆硬编。讨论后把新认识补进笔记末尾。

## 可复现实验

为每个主题保留最小复现：一段可运行的 Java 片段、一条 jcmd/jstack 命令，或一组压测对比。记录环境（JDK 小版本、CPU 核数、容器限制），结论才可靠。实验细节不必全部公开，但索引要能找到。
