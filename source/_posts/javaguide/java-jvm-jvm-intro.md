## JVM 是什么

Java 源码编译成字节码，JVM 负责解释/ JIT 执行，并提供自动 GC、线程调度、安全沙箱。一次编写到处运行，靠的是针对不同 OS 的 JVM 实现。

<!-- more -->

## 与 JRE/JDK

JDK = JRE + 开发工具；JRE = JVM + 核心类库。现在 Oracle 发行版趋向整包 JDK，但概念仍常用。

## 执行路径

javac → .class → ClassLoader 加载 → 字节码验证 → 解释执行，热点代码 JIT 编译成本地代码。理解这条链，后面学内存与 GC 才有落脚点。

## 类比

JVM 像操作系统里的「小操作系统」，管理 Java 世界的内存与线程。

## 可复现实验
