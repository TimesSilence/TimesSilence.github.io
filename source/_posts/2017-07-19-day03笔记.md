## 算术运算符

`+ - * / %`，外加自增自减 `++ --`。两个高频考点：

**整数除法与取余**：`/` 两边都是整数时结果仍是整数（直接舍去小数部分），想要小数结果必须让运算中出现浮点数；`%` 取余数，结果的符号只跟左边有关——`-5 % 3` 得 -2，`5 % -3` 得 2。一个实用规律：任何正整数 `% 2` 的结果非 0 即 1，常用来做奇偶判断和状态切换。

**++ 的前置与后置**：单独使用时 `a++` 与 `++a` 没有区别；参与运算时，前置先自增再参与，后置先参与再自增。

```java
int x = 4;
int y = (x++) + (++x) + (x * 10);
// x++  ：取 4 参与运算，然后 x 变 5
// ++x  ：x 先变 6，取 6 参与运算
// x*10 ：6 * 10 = 60
// y = 4 + 6 + 60 = 70
```

看懂即可。实际代码里**不要**在一行内对同一个变量多次自增——可读性远比炫技重要。

## 关系运算符

`== != > >= < <=`，无论操作数多复杂，结果都是 boolean 类型。最大的坑是把 `==`（比较）写成 `=`（赋值）：`if (a = 5)` 在 C 语言里能蒙混过关，在 Java 里因为赋值表达式的结果是 int 而非 boolean，编译器会直接报错拦住你——这是强类型语言的保护。

## 逻辑运算符与短路

`&` 与、`|` 或、`^` 异或（相同为 false，不同为 true）、`!` 非（偶数个 `!` 等于没写）。它们连接的都必须是 boolean 表达式。

`&&`、`||` 与单符号版本的最终结果完全一样，区别在于**短路**：`&&` 左边为 false 时右边不再执行（结果已经注定）；`||` 左边为 true 时右边不再执行。而 `&`、`|` 两边一定会计算。

短路不是可有可无的语法糖，它有真实的工程价值——利用"右边可能不执行"做空值保护：

```java
String s = null;
// if (s != null & s.length() > 0)  // 用 & 会抛 NullPointerException
if (s != null && s.length() > 0) {   // 左边为 false，右边不执行，安全
    System.out.println("非空字符串");
}
```

开发中一律使用 `&&`、`||`；只有刻意要求"两边都执行"（比如右侧有必须发生的副作用）时才考虑单符号版本。

## 位运算符

位运算符直接操作二进制的每一位：`&` 有 0 则 0，`|` 有 1 则 1，`^` 不同则 1，`~` 按位取反；`<<` 左移（右边补 0），`>>` 带符号右移（高位补符号位），`>>>` 无符号右移（高位恒补 0）。

左移 n 位相当于乘以 2ⁿ，右移 n 位相当于除以 2ⁿ——因为位权本身就是 2 的幂。所以"最有效率地算出 2 × 8"的经典答案是 `2 << 3`，它省掉了乘法指令。另一个经典面试题是"不用第三方变量交换两个数"：

```java
int a = 10, b = 20;
a = a ^ b;  // a 暂存两者的差异
b = a ^ b;  // 差异 ^ b 还原出 a，赋给 b
a = a ^ b;  // 差异 ^ 新的 b（即原来的 a）还原出 b，赋给 a
```

原理是 `x ^ y ^ y == x`：一个数被另一个数异或两次会还原自身。实际开发请老老实实用临时变量——可读性优先，这个技巧只需要看得懂。

## 三元运算符

格式：`条件表达式 ? 结果1 : 结果2;`。它的本质是一个**表达式**——必须产生一个值。求两个数的最大值：

```java
int max = a > b ? a : b;
```

三元与 if-else 的关系是单向的：三元能写的 if 都能写，反之不然。因为三元的两个分支必须是"值"，不能是输出语句这类"动作"。分支里只是算一个值时用三元，要做事时用 if。

## Scanner：让程序接收键盘输入

之前程序的数据都是写死的，用户无法参与。Scanner 解决键盘录入，固定三步：

```java
import java.util.Scanner;                    // 1. 导包（写在 class 之上）

public class ScannerDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // 2. 创建对象
        System.out.println("请输入一个整数：");
        int x = sc.nextInt();                // 3. 读取一个整数
        System.out.println("你输入了：" + x);
    }
}
```

一个常见坑：`nextInt()` 等方法读到空白符为止，**不消费换行符**，后面紧跟 `nextLine()` 会把上一步残留的换行读走，表现为"莫名其妙少读一行"。规避办法是统一用 `nextLine()` 接收再用 `Integer.parseInt()` 转换，或者在中间多调一次 `nextLine()` 把残留换行吃掉。

## if 的三种格式

```java
// 格式一：单分支
if (score >= 60) {
    System.out.println("及格");
}

// 格式二：双分支
if (num % 2 == 0) {
    System.out.println("偶数");
} else {
    System.out.println("奇数");
}

// 格式三：多分支，从上往下依次匹配，命中即执行并结束整个结构
if (score >= 90) {
    System.out.println("优");
} else if (score >= 80) {
    System.out.println("良");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

注意事项：条件必须是 boolean；语句体只有一条时大括号可以省略，但**强烈建议永远写上**——省略大括号是无数线上 bug 的共同源头；else 后面没有条件表达式；多分支的最后一个 else 可以省略，但保留它能兜住非法数据（比如成绩输入了 120 或 -5），建议保留。

## switch：为定值分支而生

```java
switch (week) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    default:
        System.out.println("非法输入");
        break;
}
```

执行流程：先计算表达式的值，依次与 case 的常量匹配，命中后顺序执行，直到遇到 `break` 或 switch 结束。要点：

- 表达式可以是 byte、short、char、int、枚举、String（JDK 7 起支持），**不能是 long、float、double、boolean**。
- case 后面必须是**常量**（或编译期可确定的值），不能是变量，且各 case 的值不能重复。
- 省略 break 会"穿透"到下一个 case 继续执行——这既是 bug 高发区，也能被故意利用（多个 case 共享一个语句体）。
- default 可以写在任意位置、也可以省略，但建议固定写在最后，兜住所有意外值。

现代 Java（JDK 14+）提供了箭头语法，自带"不穿透"语义，还能让 switch 作为表达式直接返回值：

```java
String name = switch (week) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    default -> "非法输入";
};
```

新代码推荐箭头形式；老代码里的冒号形式也必须能看懂。

## if 和 switch 怎么选

一句话：**定值用 switch，区间用 if**。判断"成绩落在哪个分数段"是区间匹配，if 的 `>=` 天然适合；判断"1~7 对应星期几"是离散定值，switch 更直观，编译器对定值跳转还可以做优化。

## 实战：判断季节

```java
import java.util.Scanner;

public class SeasonDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入月份(1-12)：");
        int month = sc.nextInt();

        switch (month) {
            case 3, 4, 5 -> System.out.println("春季");
            case 6, 7, 8 -> System.out.println("夏季");
            case 9, 10, 11 -> System.out.println("秋季");
            case 12, 1, 2 -> System.out.println("冬季");
            default -> System.out.println("月份不合法");
        }
    }
}
```

`case 3, 4, 5` 的多值写法是 JDK 14 起的新特性；老版本要写成三个连续的 case 共享一个 break，效果相同。

## 小结

- 整数 `/` 舍去小数部分，`%` 结果的符号随左边；`++` 前置先用后加、后置先加后用，不要混在一行。
- 逻辑运算用短路的 `&&`、`||`，短路可以做空值保护。
- 位运算直接操作比特：`<<` 是乘 2 的幂，`^` 异或两次还原自身。
- 三元是"必须有结果的表达式"，能返回值但干不了动作。
- if 管区间、switch 管定值；冒号 switch 记得 break，箭头 switch 不穿透；Scanner 读取注意换行残留。
