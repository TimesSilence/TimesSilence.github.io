一、项目概览

这是 Dai Wei 的个人技术网站（www.daiwei.biz），2026 年 9 月从旧版 Hexo + spfk 重建为 Hexo 8 + Butterfly。项目定位是「内容型静态站点」，核心资产不是代码而是 378 篇技术文章，代码只承担两类职责：站点生成（Hexo 生态）与内容工具链（tools/ 下 6 个 Node 脚本，约 1034 行）。

Markdown 写作→ hexo generate→ public/（45MB）→ GitHub Actions→ GitHub Pages + CNAME
内容系列数量说明
2017 年 Java 入门笔记27 篇从旧站 HTML 抽取（extract）并改写为系统化教程（optimize）
JavaGuide 衍生笔记350 篇以固定 commit aa4dc79 为源重新组织，Apache-2.0 许可证合规存档
每日技术动态 daily1 篇2026-09-20 启动的新系列，配套写作手册 daily-article-playbook.md

1. 项目概览

优秀

优秀

良好

良好

  • 缺口：validate 未接入 CI，内容回归靠人肉记得跑

6. 依赖供应链

优秀
  • 14 个生产依赖全部为 Hexo 官方生态，npm outdated（官方源）确认全部最新
  • lock 文件入库 + CI 用 npm ci，构建可复现
  • Dependabot 双生态（npm daily + actions weekly）已配置

7. 工程化

优秀
  • Pages 部署走官方 Actions 路径，concurrency 防重复部署
  • Giscus 评论、本地搜索、Atom feed、Open Graph 一应俱全
  • daily-article-playbook.md 是难得的内容 SOP：选题查重、事实纪律、人工审核门禁

8. 安全与性能

良好
  • 密钥扫描（tools/ + source/）零泄露；部署用 OIDC 最小权限（contents: read）
  • 构建极快；但图片未做懒加载/压缩，第三方脚本走 jsdelivr（国内可访问性一般）
